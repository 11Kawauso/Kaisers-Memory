// ===== カイザーのセリフ（トップページ右下） =====
// ※ 今のセリフは仮です。自由に書き換えてOK。
//
// 書き方
//   # 名前            … 場面の始まり。最初は「# start」から始まります
//   [表情] セリフ     … 1行が1回分のセリフ。[表情] は省略すると前と同じ表情のまま
//   ? 選択肢 -> 場面  … 選択肢。押すと「場面」へ進みます。すぐ上のセリフと一緒に出ます
//   -> 場面           … 別の場面へ進む
//   @room             … カイザーの部屋へ行く
//   @about            … 「作者について」を開く
//   @end              … 会話を終わる
//   《ひらがな》      … 独自文字（四角五線 Font）で表示する部分
//   en: ...           … すぐ上のセリフ／選択肢の英語版（Claude が書きます）
//   // ...            … メモ（サイトには出ません）
